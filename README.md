## 📝 Getting Started

To compile and run the C programs:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Reet-Kamlay/C-Programming-tutorials.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd C-Programming-tutorials
   ```
3. **Compile a C program**:
   ```bash
   gcc filename.c -o filename
   ```
4. **Run the executable**:
   ```bash
   ./filename
   ```

*Note: Replace `filename` with the actual name of the C file you wish to compile and run.*
